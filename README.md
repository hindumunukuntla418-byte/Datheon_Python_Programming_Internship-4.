# Stock Portfolio Performance Tracker

## Project Description
A Python-based stock portfolio tracking application that calculates investment value, current market value, and profit or loss for individual stocks and the overall portfolio.

## Features
- Enter stock ticker symbols.
- Enter buying prices and share quantities.
- Enter current stock prices.
- Calculate total investment.
- Calculate current portfolio value.
- Calculate individual stock profit and loss.
- Calculate overall portfolio percentage return.
- Automatically save performance records to a CSV file.

## Technologies Used
- Python 3
- CSV module
- File Handling
- Datetime module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python portfolio.py
```
